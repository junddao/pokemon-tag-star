# 태그스타 도감

포켓몬 태그스타 비공식 팬사이트. 태그 도감과 중고 시세, 트레이드 손익 계산기, 내 주변 설치 매장 지도를 제공합니다.

> 비공식 팬사이트입니다. 포켓몬 및 포켓몬 태그스타의 권리는 각 권리자에게 있습니다.
> 시세는 중고 거래 매물을 모아 추정한 참고값이며 실제 거래가를 보장하지 않습니다.

## 시작하기

```bash
npm install
npm run scrape   # 공식 사이트·시세 수집 → public/data/*.json, public/tags/*.png
npm run dev      # http://localhost:3000
```

`public/data` 가 비어 있어도 화면은 뜨지만 내용이 없습니다. 처음 받았다면 `npm run scrape` 를 먼저 돌리세요.

| 명령 | 설명 |
|---|---|
| `npm run scrape` | 전체 수집 |
| `npm run scrape -- --no-prices` | 시세를 건너뛰고 태그·매장만 (직전 시세를 재사용) |
| `npm run scrape -- --no-images` | 이미지 내려받기를 건너뜀 (직전 로컬 경로를 이어붙임) |
| `npm test` | 파서·시세 필터·점수·트레이드 판정 테스트 |

## 구조

```
scripts/scrape.ts      수집 오케스트레이터 (네트워크·파일쓰기·안전장치)
src/lib/
  parse-official.ts    공식 사이트 HTML 파서
  parse-prices.ts      중고 매물 필터와 중앙값
  rarity.ts            등급 체계, 표본 하한, 가치 상한
  scoring.ts           거래점수(TP) 확정
  trade.ts             트레이드 판정·사다리 경고·추가 추천
  geo.ts               거리 계산
public/data/*.json     화면이 읽는 데이터 (그대로 공개 API 로도 쓰인다)
```

`public/data/*.json` 은 `https://<도메인>/data/tags.json` 처럼 그대로 노출됩니다.
나중에 네이티브 앱을 붙일 때 서버를 새로 만들지 않고 이 URL을 그대로 쓰면 됩니다.

도감이 통째로 빈 화면이 됩니다.

### 거래점수(TP)

가치가 비선형이라 원화를 그대로 더하면 거짓말이 됩니다. ★4 이하는 사실상 0이고
★6 안에서도 편차가 몇 배로 벌어지기 때문입니다.

- 실거래 표본이 등급별 하한을 넘으면 중앙값을 TP 로 환산 (400원 ≈ 1TP)
- 넘지 못하면 `등급 기본값 × 인기 가중치` 로 추정하고 화면에 "추정치" 표시
- 어느 쪽이든 등급별 상한을 넘지 못하도록 자릅니다 — 표본 세 개짜리 ★3이 ★5보다
  비싸게 평가되는 것을 막기 위한 장치입니다

### 등급 사다리

합계 TP 가 같아도 ★6은 ★5 뭉치로 바뀌지 않습니다. 계산기는 이런 조합을 따로 경고합니다.
수량으로 메울 수 없는 구간을 알려주는 것이 이 계산기의 존재 이유입니다.
