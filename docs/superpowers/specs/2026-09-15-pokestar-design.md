# 포켓몬 태그스타 팬 서비스 — 설계

작성일: 2026-09-15
상태: 확정 (구현 진행)

## 1. 무엇을 만드는가

포켓몬 태그스타(pokemontagstar.co.kr) 플레이어를 위한 비공식 팬 서비스.
공식 사이트에 없는 세 가지를 제공한다.

1. **등급/시세가 붙은 도감** — 공식 사이트는 태그 목록만 주고 가치 정보가 없다
2. **트레이드 계산기** — 누가 손해인지, 뭘 더 얹어야 하는지 판정
3. **내 주변 설치장소 지도** — 공식은 주소 목록 + 페이징뿐이라 "가까운 곳"을 못 찾는다

### 하지 않는 것 (YAGNI)

- 로그인 / 회원 / 서버 저장 — 어린이 대상이라 개인정보를 받는 순간 만 14세 미만 법정대리인 동의 절차가 법적 의무가 된다. 보유 태그는 브라우저 localStorage에만 둔다
- 직거래 중개 / 채팅 / 결제
- PWA (설치, 오프라인, 서비스워커)

### 전제

비영리 팬사이트. 포켓몬 IP 자산(이미지·이름)을 쓰므로 광고·수익화는 하지 않는다.
모든 페이지에 비공식 고지를 둔다.

## 2. 기술 스택

| 레이어 | 선택 | 근거 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 도감/시세를 정적 생성해 검색 유입을 받는 것이 이 서비스의 생명줄 |
| 형태 | 모바일 반응형 웹 | 주소 하나. 자이로·GPS·AR은 브라우저 API로 전부 동작 |
| 데이터 저장 | **레포 안의 정적 JSON** | 태그 146개 + 매장 372개. DB를 세울 규모가 아니다 |
| 지도 | Leaflet + OSM 타일 | 공식 사이트가 정확한 위경도를 주므로 지오코딩이 불필요 → 카카오맵 SDK의 이점이 사라지고, API 키 없이 동작한다. 길찾기만 카카오맵 웹 링크로 딥링크 |
| 스타일 | Tailwind CSS | |
| 배치 | GitHub Actions (매일 06:00 KST) | JSON 갱신 후 커밋 → 배포 자동 트리거 |

### 설계 변경 이력

- **Supabase(Postgres+PostGIS) → 정적 JSON**: 데이터가 수백 건 규모라 DB가 과설계였다.
  반경 검색은 372개 대상 하버사인 계산이 네트워크 왕복보다 빠르다. 인프라 비용 0, 로컬 실행에 자격증명 불필요
- **카카오맵 → Leaflet+OSM**: 위 표의 근거 참조. 카카오는 길찾기 딥링크로만 사용

## 3. 데이터 소스

### 3.1 공식 사이트 (하루 1회)

| 대상 | URL | 파싱 방법 |
|---|---|---|
| 태그 | `/kr/sub/stage.php?cate={1,4}` | `<p class="cm-border-txt">` 등급 헤더로 분할 후 `tag-list-item` 추출 |
| 태그 앞/뒷면 | `/kr/sub/stage_pop_view.php?idx=N` (POST) | `card-pop-list` 안의 img 2장 |
| 설치장소 | `/kr/sub/place.php` | 페이지 JS의 `listData2`(매장명) / `listData`(주소) / `coordY`(위도) / `coordX`(경도) 배열. 372건 전부 한 페이지에 있다 |

주의: 공식 사이트의 `coordX`는 경도, `coordY`는 위도다. 변수명이 뒤집혀 있으므로 그대로 믿지 말 것.

현재 규모: 1탄 73개 + 2탄 73개. 등급 구성은 탄마다 ★6:10 / ★5:15 / ★4:17 / ★3:14 / ★2:14 / 레귤러:3.

이미지는 핫링크하지 않고 `public/tags/` 에 내려받아 보관한다. 공식 서버 부하를 주지 않고, 파일이 교체돼도 화면이 깨지지 않는다.

### 3.2 중고 시세 (하루 1회)

번개장터 검색 API(`api.bunjang.co.kr/api/1/find_v2.json`)로 태그별 매물가를 수집한다.

검색 결과에는 노이즈가 많아 반드시 걸러야 한다. 실제 관측된 오염 사례:

- 묶음 판매 — `"가이오가,그란돈 6성"`, `"2탄 5종"`, `"일괄택포"`
- 다른 게임 — `"메자스타 스페셜 태그 3종"`

필터 규칙: 제목에 다른 태그 이름이 함께 있거나, `메자스타`·`일괄`·`세트`·`묶음`·`N종` 이 포함되면 제외. 남은 매물의 **중앙값**을 쓴다(평균은 이상치에 끌려간다). 표본 3건 미만이면 시세로 인정하지 않고 추정값으로 폴백한다.

## 4. 거래점수(TP) — 트레이드 계산기의 핵심

### 4.1 왜 원화를 그대로 안 쓰는가

가치가 비선형이다. ★4 이하는 사실상 0이고, ★6 안에서도 편차가 몇 배로 벌어진다.
원화를 단순 합산하면 "★5 스무 장 = ★6 한 장" 같은 현실에서 성립하지 않는 결론이 나온다.

### 4.2 산식

```
TP = base(등급) × popularity(포켓몬) × scarcity(한정 여부)
```

| 등급 | base | 의미 |
|---|---|---|
| 레귤러 / ★1~★4 | 0.5 | 덤. 백 장을 쌓아도 저울이 안 움직인다 |
| ★5 | 10 | 인기 포켓몬이면 상단 |
| ★6 | 80 | 편차가 여기서 폭발한다 |

실거래 표본이 3건 이상이면 중앙값으로 TP를 덮어쓰고 `confidence: "market"`,
아니면 산식 추정값에 `confidence: "estimated"` 를 붙여 화면에 "추정치" 뱃지를 노출한다.

### 4.3 계산기가 내놓는 것

1. **판정** — 양쪽 합산 TP 차이 비율로 5단계: 크게 손해 / 약간 손해 / 공정 / 약간 이득 / 크게 이득
2. **사다리 경고** — 합계가 맞아도, 상대의 최고 등급보다 낮은 태그만 쌓아 올린 경우 경고한다.
   현실에서 ★5 스무 장으로 ★6 한 장은 바뀌지 않는다. 수량으로 메울 수 없는 구간을 따로 알려주는 것이 이 계산기의 존재 이유다
3. **추가 추천** — 내 보유 목록에서 부족한 TP를 가장 가깝게 메우는 조합을 제안한다(초과 지불 최소화)

## 5. 화면

| 경로 | 내용 | 렌더링 |
|---|---|---|
| `/` | 홈 — 최신 탄, 시세 상위, 바로가기 | 정적 |
| `/dex` | 도감 — 탄별·등급별 필터, 시세 정렬 | 정적 |
| `/dex/[no]` | 태그 상세 — 프리즘 뷰어, 시세 추이, TP | 정적 (태그당 1페이지, SEO 핵심) |
| `/trade` | 트레이드 계산기 | 클라이언트 |
| `/map` | 내 주변 설치장소 | 클라이언트 |

반응형: 도감 그리드는 PC 6열 / 폰 2열, 상세는 PC 좌우 분할 / 폰 수직 적층, 지도는 PC 목록+지도 / 폰 전체지도+하단시트.

### 5.1 프리즘 뷰어

CSS 3D `rotateX/rotateY` 위에 홀로그램 레이어 2장(`glare`, `pattern`)을 `mix-blend-mode`로 합성한다. WebGL을 쓰지 않으므로 저가 안드로이드에서도 60fps가 나오고 발열이 없다.

- PC: `mousemove` → 각도
- 모바일: `deviceorientation` → 각도. **iOS 13+ 는 사용자 제스처 안에서 `requestPermission()` 를 호출해야 하므로 "기울여보기" 버튼을 한 번 노출한다**
- 탭하면 앞/뒤 뒤집기 (공식이 앞면·뒷면을 모두 제공)
- `prefers-reduced-motion` 존중

## 6. 견고성

스크래퍼는 남의 사이트에 의존하므로 깨지는 것이 정상이라고 가정한다.

- 하루 1회만 요청. User-Agent에 연락처를 명시하고 robots.txt를 존중한다
- **수집 결과가 0건이면 기존 데이터를 덮어쓰지 않고 실패로 기록한다.** 이 장치가 없으면 공식 사이트 개편 하루 만에 도감이 통째로 빈 화면이 된다
- 태그 수가 직전 대비 20% 이상 줄어도 같은 규칙으로 막는다
- 모든 실행을 `data/scrape-runs.json` 에 남긴다

## 7. 테스트

| 대상 | 방법 | 막으려는 것 |
|---|---|---|
| 공식 파서 | 저장해 둔 HTML 픽스처 단위 테스트 | 사이트 구조 변경을 조용히 넘어가는 것 |
| 시세 필터 | 실제 오염 제목(`"가이오가,그란돈 6성"`, `"메자스타 3종"`)으로 단위 테스트 | 묶음 매물이 시세를 왜곡하는 것 |
| TP / 판정 | 경계값 — ★5 20장 vs ★6 1장이 사다리 경고를 띄우는지 | 계산기가 현실과 어긋난 조언을 하는 것 |
| 스냅샷 가드 | 0건·급감 시 쓰기 거부 | 데이터 전멸 |
